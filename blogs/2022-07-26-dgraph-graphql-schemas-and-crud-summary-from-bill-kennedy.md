After learning that Dgraph has native support for GraphQL , Bill Kennedy switched gears and re-wrote his original Dgraph tutorial to show how to use Dgraph with the native GraphQL support. Bill uses the same schema but now uses the GraphQL based CRUD API provided by Dgraph to run mutations and queries. Getting Dgraph up and running with GraphQL is straightforward, and there’s a lot you can achieve with Dgraph and GraphQL.
